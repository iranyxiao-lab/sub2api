# 账号智力测试

管理员在账号管理页可打开题库，添加只有标题和提示词的题目；每个账号可单独选择文本模型、题目、附加提示词和五段式 cron 表达式。保存计划后可立即测试，也可启用定时执行。每次轮换一道题，执行历史保存当时的题目、完整提示词、模型、响应和耗时；编辑题库不改变已有历史。

- 不设置选项或标准答案，也不进行自动判分或人工评分。结果页只展示执行状态、模型响应、错误、提示词和耗时；旧记录仍可查看，但不展示原有答案与分数。
- 模型响应可以在无脚本、无网络访问的隔离框架中静态预览 HTML。不要在提示词和响应中写入密钥或用户隐私信息；结果保留数量可在计划中设置（最多 200 条）。
- 智力测试仅支持文本模型，不会自动恢复账号状态。计划至少间隔 15 分钟；每次运行会调用上游模型并产生相应流量和费用。建议先用低频计划、小型题集验证所选账号和模型。
- 运行失败的记录展示错误信息；被删除的计划及其历史会一并删除。多实例共享数据库领取锁，过期任务可由后续轮询重新领取；异常中断后可能需要检查历史确认实际执行情况。

后续可考虑增加题库版本、按成本预算自动暂停与结果导出；这些能力目前尚未实现。
